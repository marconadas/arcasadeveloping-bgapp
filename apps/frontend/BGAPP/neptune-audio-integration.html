🌊 Neptune Audio Integration Template

📋 Instruções de Integração

1️⃣ Adicionar o arquivo de áudio

Coloque seu arquivo de música oceânica em:

/apps/frontend/BGAPP/assets/audio/neptune-ambient.mp3

2️⃣ Copiar o HTML Audio

Adicione este código no body do index-neptune.html (antes do fechamento do body):

<!-- NEPTUNE BACKGROUND AUDIO -->
<audio id="neptune-bg-music" loop preload="auto">
  <source src="/assets/audio/neptune-ambient.mp3" type="audio/mpeg">
  <source src="/assets/audio/neptune-ambient.ogg" type="audio/ogg">
  Your browser does not support the audio element.
</audio>

3️⃣ Adicionar os Controles de Áudio

Copie todo o HTML dos controles (veja no código-fonte deste arquivo)

4️⃣ Copiar o CSS

Adicione os estilos CSS no <style> do index-neptune.html

5️⃣ Adicionar o JavaScript

Copie o código JavaScript completo no <script> do index-neptune.html

📁 Estrutura de Diretórios

apps/frontend/BGAPP/
├── index-neptune.html
└── assets/
    └── audio/
        ├── neptune-ambient.mp3
        └── neptune-ambient.ogg (opcional, para fallback)

🎵 Recomendações de Música

  • Estilo: Ambient oceânico, científico, relaxante
  • BPM: 60-80 (profissional e calmo)
  • Duração: 3-5 minutos (loop seamless)
  • Formato: MP3 192kbps
  • Volume inicial: 30-40% (não intrusivo)

🎨 Fontes de Música Gratuita

  • Bensound.com - Música livre de royalties
  • Free Music Archive - Arquivo de música gratuita
  • Incompetech - Kevin MacLeod (CC BY)
  • ccMixter - Remixes Creative Commons
✅ Funcionalidades Incluídas:
  • Modal de boas-vindas com opção de ativar áudio
  • Botão toggle play/pause com animação
  • Controle de volume com slider
  • Fade in/out suave
  • Persistência de preferências (localStorage)
  • Indicador visual quando áudio está tocando
  • Responsivo para mobile
